# Dizai Serif

Chữ glyphic loe nét, tương phản theo bút dẹt, tỉ lệ La Mã cổ điển. Hiện có bản
Regular (hoa A–Z, số 0–9) và Bold (A–T). Chưa có chữ thường và dấu tiếng Việt.

- `docs/01-nghien-cuu-va-concept.md`: thể loại, ẩn dụ, so sánh với các bộ anh em,
  6 điểm cần duyệt
- `docs/02-so-do-va-qa-regular.md`: số đo bản Regular và kết quả QA v0.1
- `.claude/skills/dizai-serif-design`: rule book S1–S14 (chỉnh từ skill Định Tường)
- `.claude/skills/dizai-serif-qa`: checklist QA/QC riêng của dự án
- `reference/`: ảnh bảng chữ dùng để đo
- `tools/measure_sheet.py`: đo ảnh bảng chữ (cap = 700 u)
